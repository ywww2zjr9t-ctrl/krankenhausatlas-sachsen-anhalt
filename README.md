# Krankenhausatlas Sachsen-Anhalt 0.02

Durchsuchbares Krankenhausverzeichnis Sachsen-Anhalt, veröffentlicht über GitHub Pages.

Datenquelle: InEK/GKV-Standortverzeichnis, Abruf 17.07.2026, Bundesland 15, Einrichtungstyp 00.

Die Webanwendung befindet sich in `index.html` und benötigt keinen Server.

GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).
